# Prototipo retirado

Este directorio conserva únicamente esta nota histórica. El complemento Godot instalado dentro de proyectos fue retirado del flujo activo porque duplicaba la inspección de solo lectura que ahora ofrece el agente C++ integrado en el binario Godot Web.

No copiar este addon a juegos ni activar overlays para habilitar el controlador. El agente Web debe permanecer en el motor; el puente del editor nativo se instala únicamente en una copia aislada y desechable, nunca en el proyecto fuente.
