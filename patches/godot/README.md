# Godot engine patches

Place project-specific unified diff files here, named in application order (for example, `0001-editor-bridge.patch`).

Patches are applied only to the local working tree created from the pinned `engine/godot` submodule. Never commit changes directly to the upstream submodule checkout. Each patch must be reviewed and checked against the pinned Godot commit before use.

The directory is intentionally empty until the first engine integration patch is implemented and tested.
